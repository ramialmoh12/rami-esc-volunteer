## Publish on GitHub Pages

1. Sign in to GitHub.
2. Create a new public repository, for example: `rami-volunteer-resume`.
3. Upload all files and folders from this project.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then click **Save**.
7. GitHub will show the public website address after deployment.

The final address will usually look like:

```text
https://YOUR-USERNAME.github.io/rami-volunteer-resume/
```

## Responsive support

This version has been rebuilt and checked for fluid behavior across:

- Small phones from 320px wide
- Standard phones from 360px to 480px
- Tablets in portrait and landscape
- Laptops and desktop screens
- Touch navigation and reduced-motion settings

The mobile navigation is hidden with visibility and opacity rather than moving it outside the screen, preventing unwanted horizontal scrolling.
