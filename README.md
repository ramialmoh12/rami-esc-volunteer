# Rami Almohamad — Volunteer Portfolio Website

A responsive one-page online resume designed for European Solidarity Corps and NGO volunteering applications.

## Files

- `index.html` — website structure and resume content
- `styles.css` — full responsive design, mobile layout and dark mode
- `script.js` — mobile navigation, theme switcher, active navigation and reveal animations
- `assets/Rami_Almohamad_Volunteer_CV.pdf` — downloadable PDF CV
- `assets/favicon.svg` — browser icon

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `volunteer-resume`.
2. Upload all files and folders from this package. Keep `index.html` in the repository root.
3. Open the repository’s **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will provide the public website address after deployment.
